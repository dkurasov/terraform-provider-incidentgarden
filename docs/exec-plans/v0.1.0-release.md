## Release infrastructure decisions

- GoReleaser follows HashiCorp's provider scaffolding conventions.
- The Registry manifest declares protocol `6.0`.
- Release archives inject the semantic version into `main.version`.
- Checksums cover archives and the renamed Registry manifest.
- GPG signs the checksum file with a binary detached signature.
- Manual workflow dispatch is snapshot-only. SemVer-shaped `v*` tags run release
  checks and require approval from the protected `release` environment before
  creating a signed draft GitHub release.
- The RC tag is not represented as a separate Changie version, preserving the
  existing `0.1.0` notes for the final release.
